# Data

⚠️ **Jangan simpan data besar atau data terbatas di sini.** Ikuti [kebijakan data Pokja 2](https://github.com/idtc-id/pokja2-handbook/blob/main/docs/04-kebijakan-data.md).

- `catalog.yml` — daftar seluruh dataset pilot beserta pemilik, izin, dan lokasi penyimpanan.
- `sample/` — sampel kecil data **terbuka** untuk uji dan contoh (≤ 50 MB per file).
